Vis opsætningsvejledning
A. Opret Google Cloud projekt og OAuth credentials
1. Gå til console.cloud.google.com
2. Opret et nyt projekt (eller vælg eksisterende)
3. Gå til APIs & Services → Library og søg efter "Google Drive API" → aktivér den
4. Gå til APIs & Services → Credentials
5. Klik Create Credentials → OAuth client ID
6. Vælg Web application
7. Under Authorized redirect URIs tilføj: https://developers.google.com/oauthplayground
8. Klik Create — kopiér Client ID og Client Secret ind i felterne ovenfor

B. Tilføj testbruger
9. Gå til APIs & Services → OAuth consent screen
10. Klik på Audience i venstremenuen
11. Under Test users tilføj din Google-konto (f.eks. din Gmail-adresse)

C. Hent Authorization Code
12. Gem Client ID og Secret i felterne ovenfor først
13. Åbn Google OAuth Playground
14. Klik på tandhjulet øverst til højre → sæt flueben i "Use your own OAuth credentials" → indtast Client ID og Secret
15. Skriv dette scope i feltet: https://www.googleapis.com/auth/drive.readonly
16. Klik "Authorize APIs" → log ind med din Google-konto → klik "Continue" forbi advarslen
17. Klik "Exchange authorization code for tokens" → kopiér Authorization code
18. Sæt koden ind i feltet ovenfor og klik Save inden 60 sekunder — koden udløber hurtigt!

Efter første godkendelse gemmes et refresh token automatisk, og du behøver ikke gentage processen.

Lad stå tomt for billeder fra hele dit Drive. Find mappe-ID i URL'en på Google Drive: drive.google.com/drive/folders/[MAPPE-ID]
