Spotify Opsætningsvejledning
A. Opret Spotify Developer App
1. Gå til developer.spotify.com/dashboard
2. Klik "Create app" — giv den et navn (f.eks. InkyPi)
3. Under Redirect URIs tilføj: http://127.0.0.1:8080/callback
4. Under APIs used vælg Web API
5. Gem og kopiér Client ID og Client Secret ind i felterne nedenfor

B. Hent Authorization Code
6. Start musik på din Spotify-konto
7. Åbn et inkognito-vindue (vigtigt — koder kan kun bruges én gang)
8. Indtast Client ID i feltet nedenfor og klik "Åbn Spotify Login"
9. Log ind med din Spotify-konto og accepter adgang
10. Du bliver sendt til en side der ikke eksisterer — kopiér koden fra URL'en:
   http://127.0.0.1:8080/callback?code=[DIN KODE]
11. Sæt koden ind i feltet nedenfor og klik Update Now

Efter første opsætning gemmes et refresh token automatisk i spotify_token.json — du behøver ikke indtaste noget igen.
